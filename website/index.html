不只是一個鍵盤

從選字到出版，
每一步都留給你。

小麥注音的功能不是一張名詞清單。它們來自長期的使用與開發：有人需要更準確的聯想詞，有人需要輸入教材注音，也有人只想把自己的詞加進去。以下用幾個實際場景，快速看懂它能做什麼。

01 / 04

候選字不是猜謎，是一條可以調整的路。

小麥注音用語料與讀音資料建立選字模型，從輸入的注音找出更可能的字詞。候選字太長時，仍可在組字區中移動游標，逐段確認自己的選擇。

常見問題

還在想這是不是你要的？

先從這幾個答案開始。如果找不到，需要更完整的說明，請直接進入使用手冊。

小麥注音和 macOS 內建注音有什麼不同？

小麥注音是一個獨立的開源專案，提供可調整的鍵盤配置、自訂詞彙、可追蹤的詞庫與較多文字轉換服務。若你希望輸入法能配合自己的詞彙和工作流程，可以從小麥注音開始比較。

只支援 macOS 嗎？

macOS 是主要版本；另有 Linux / FreeBSD、Chrome OS 與網頁版入口。不同平台的安裝與功能範圍請從上方平台區選擇。

如何回報選字或詞庫問題？

請前往 GitHub 的問題回報入口，說明輸入的注音、實際候選字、期望結果與使用的版本。越能重現，越容易協助修正。

小麥注音的選字原理是什麼？

引擎會依照辭典與語料建立候選路徑，再用簡化的 n-gram 模型估計最可能的字詞組合；技術文章也說明了如何用 DAG 最短路徑演算法取消組字區字數上限。
